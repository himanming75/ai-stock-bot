E*TRADE Primary.

safe state after restart, blocks profile changes while locked, requires
operator acknowledgement for release actions, and forces ALL_STOP under
critical conditions.

The implementation remains registry- and profile-driven so more accounts or
brokers can be added later without replacing the controller architecture.
