This bundle preserves all planned functionality while consolidating repetitive stage packaging.

Functional scope:
- Automation certificate chain
- Portfolio state and cash reservation
- Fill application and mark-to-market
- Position, cash, and equity reconciliation
- Symbol and total exposure management
- Pre-trade runtime risk engine
- Daily order, notional, position, daily-loss, and drawdown guards
- Kill switch
- Duplicate signal prevention
- Deterministic replay
- Rollback package
- Integrated runtime simulation
- Final audit and PAPER_RUNTIME_RC1 certification
