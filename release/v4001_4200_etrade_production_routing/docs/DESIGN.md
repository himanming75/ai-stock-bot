This stage adds E*TRADE account routing and Production read-only guards without
performing Production network access. Multiple E*TRADE accounts can be given
aliases, allowlisted, disabled, and assigned a default route.

Production read access requires both ETRADE_ENVIRONMENT=PRODUCTION and
ETRADE_ALLOW_PRODUCTION_READ=YES. Order submission and cancellation remain
disabled regardless of the read policy.
