# V3.17 Strategy Weakness Map

V3.17 aggregates V3.11-V3.16 analytics into a diagnostic weakness map.

## Critical design rule
A weakness is classified as one of two types:

- `EVIDENCE_GAP`: the system does not yet have enough evidence.
- `PERFORMANCE_RISK`: the observed data shows an adverse performance characteristic.

An `EVIDENCE_GAP` is NOT proof that the strategy is bad.

## Current small-sample behavior
With fewer than 10 canonical numeric trades:
- sample weakness is `CRITICAL / EVIDENCE_GAP`
- stress and robustness remain evidence-limited
- no-profitability weakness is created merely because the current tiny sample is all winners
- no-loss history is marked as unobserved downside evidence, not as proof of safety
