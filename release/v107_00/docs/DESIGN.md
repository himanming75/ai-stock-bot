# V106.01–V107.00 Portfolio & Fill Accounting Foundation

Implemented real portfolio accounting components:

- cash ledger
- long-only position ledger
- weighted average cost
- partial and full fill application
- realized P/L
- unrealized P/L
- market value
- equity
- buying power
- duplicate fill protection
- rejected execution handling
- `execution.update` to `portfolio.snapshot` EventBus bridge

This stage performs no broker communication.
