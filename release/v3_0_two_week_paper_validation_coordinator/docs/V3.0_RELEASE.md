# V3.0 Two-Week Paper Validation Coordinator

## Roadmap role
This is the closing validation coordinator for Stage 1: fully autonomous Paper trading + two-week validation.

## No duplicate engine
V3.0 does not create another trading loop, strategy engine, broker client, scheduled task, or order path.

It reuses:
- V2.9.4 runtime observation gate
- V2.8.1/V2.8.2 hook ledger
- existing autonomous Paper session ledger

## Start gate
The two-week validation clock does not start until the existing V2.9.4 gate has at least 3 successful runtime shadow hooks.

## Two-week definition
Two weeks is measured as 10 eligible trading days.
A day is eligible when at least 3 successful shadow-hook observations exist on that ET trading date.

## States
- PASS_WAITING_FOR_RUNTIME_GATE
- PASS_GATE_MET_WAITING_FOR_FIRST_ELIGIBLE_TRADING_DAY
- PASS_TWO_WEEK_VALIDATION_ACTIVE
- PASS_TWO_WEEK_PAPER_VALIDATION
- BLOCKED_TWO_WEEK_VALIDATION_INTEGRITY

## Safety
No runtime start, broker write, Paper/live order submission, strategy/selector modification, or automatic promotion.
