verification-code, access-token, renew, revoke, and token-state workflow.

Installation, unit testing, and certification use fixture OAuth responses and
do not access E*TRADE. The explicit sandbox read runner is separate and only
uses network access after the operator supplies Sandbox credentials through
environment variables.

Order submission and cancellation remain blocked by the E*TRADE read-only
adapter and the multi-broker core safety contract.
