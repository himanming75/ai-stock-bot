# V114-V116 Manual Approval Guide

This stage creates a manual approval package but does not provide a command that approves or submits live orders.

Current safeguards:

- Approval required
- Approval not granted
- Approval token not issued
- Broker submission disabled
- External network disabled
- Live trading disabled
- Actual orders submitted: zero

The translated Alpaca, IBKR and E*TRADE payload structures are local previews only.
