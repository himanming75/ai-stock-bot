# AI V2 Mega Bundle 2 — Intelligence Platform

This is the first of the final two large AI V2 bundles.

Included:

- Stock Scanner;
- Technical Indicator Engine;
- Market Regime Detector;
- News and Economic Event Scoring Framework;
- Earnings Event Framework;
- Sector Rotation Analyzer;
- Watchlist Ranking;
- Strategy Explanation Engine;
- Dashboard 2.0 read-only data model;
- Historical Data Adapter;
- Offline end-to-end qualification.

The event framework accepts normalized event records but does not connect to an
external news provider. The explanation engine creates deterministic,
transparent reasons and does not call an LLM API.

The Dashboard 2.0 model is read-only and exposes no broker action. No market
network, broker network, broker write, portfolio mutation, or order submission
occurs.
