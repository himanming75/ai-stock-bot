# V3.2 Unified Operations Dashboard

## Purpose
Unify the V3.1 validation/health dashboard with account, positions, orders, P/L, shadow, and timeline views.

## Historical vs current validation
Historical Paper closed trades are separated from current V3.0 10-trading-day validation closed trades.

This resolves the confusing but valid case where:
- Validation Closed Trades = 0
- Historical CLOSED_TRADE records already exist

## Data source policy
V3.2 makes no broker request.

It reads existing runtime JSON/JSONL files and normalizes common saved fields for:
- equity
- cash
- buying power
- positions
- open orders
- closed trades
- realized P/L

If saved runtime files do not contain a value, the dashboard displays `-` instead of inventing one.

## URL
http://127.0.0.1:8765

## Safety
GET-only, localhost-only by default, no broker network/write, no order submission, no runtime/strategy/selector changes.
