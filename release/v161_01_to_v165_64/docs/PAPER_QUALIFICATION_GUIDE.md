# V161-V165 Paper Qualification Center

The center evaluates:

- trading days
- closed trades
- win rate
- gross profit and gross loss
- profit factor
- average trade PnL
- Sharpe ratio
- maximum drawdown
- reconciliation errors
- duplicate orders
- critical errors
- strategy rankings
- rolling 5, 20 and 60 day scores

A PASS does not enable Live trading. It only allows the next Live Read-Only review phase.
