# AI Monitoring and Distributed Runtime Mega Bundle

This package adds:

- a read-only AI monitoring dashboard;
- health, risk, strategy, and shadow portfolio monitoring;
- metrics and summary feeds;
- alert feed generation;
- symbol task queue;
- offline worker pool;
- parallel scanner simulation;
- load balancing;
- scheduler preview;
- runtime health monitoring;
- recovery queue preview.

The runtime is not started automatically. Scheduler and recovery features are
preview-only. No market data network, broker network, broker read, broker write,
or order action occurs.
