# Personal Web Control Center — Daily Command Center

This is a UI consolidation only. It reuses existing APIs and does not create
another broker, risk, AI, qualification, or scheduler backend.

The dashboard now summarizes:
- current market state;
- Paper account equity/cash/buying power;
- current positions/open orders;
- risk gate;
- AI model health and validation state;
- Paper qualification state;
- Emergency Stop and live safety locks;
- latest autonomous cycle.

Quick navigation/actions:
- refresh;
- AI status;
- strategy/risk;
- daily operations;
- qualification;
- Emergency Stop ON/OFF.

No live-trading capability is added.
