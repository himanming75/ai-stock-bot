# V85.21-V85.40 Release Notes

- Six Alpaca Paper/Market Data GET endpoints: account, clock, positions, orders snapshot, asset, and latest quote
- Explicit three-part network opt-in: CLI flag, config flag, and environment value
- Paper credentials read only at execution time and never persisted
- Offline-safe default pipeline plus separate actual-network read-only script
- Schema, health, reconciliation, TLS, redaction, retry classification, rate-limit observation, audit, ledger, manifest, and certificate
- No POST, PUT, PATCH, DELETE, order creation, cancellation, replacement, or live trading
