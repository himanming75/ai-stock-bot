This engine is a dry-run submission simulator. It transforms approved broker
request JSON into immutable submission envelopes and maps simulated HTTP
responses into accepted, rejected, retry, and recovery states.

It contains no HTTP client, broker SDK, credential loader, POST execution,
registry mutation, or actual Paper/Live submission capability.
