# V2.9.2 Scheduled Task / Runtime Activation Audit

## Purpose
Confirm that the Windows Scheduled Task which launches the autonomous Paper session is ready to execute the current `C:\stock-bot` code containing the V2.8.2 shadow hook.

## What is inspected
- Windows Scheduled Tasks and their action text
- exact use of `RUN_PAPER_AUTONOMOUS_DAILY_SESSION.ps1`
- task state, next run, last run and last result
- Git branch / HEAD / origin-main alignment
- `paper_daily_session/runner.py` compile status
- exactly one V2.8.2 shadow method and one polling-loop call
- `session.lock` existence, PID and whether the PID is alive
- STOP existence (observation only)
- V2.8.1 hook ledger and V2.7 shadow ledger existence
- previous V2.9 certification state

## Safety
This is intentionally audit-only:
- does not enable, disable, start, register, unregister or edit Scheduled Tasks
- does not remove STOP
- does not remove session.lock
- does not start Paper runtime
- does not connect to a broker
- does not submit Paper or live orders
- does not modify strategy or selector settings

If a blocker is found, the report uses a BLOCKED status so the next repair can target only the confirmed issue.
