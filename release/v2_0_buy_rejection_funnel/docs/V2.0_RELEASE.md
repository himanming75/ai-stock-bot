# V2.0 BUY Candidate Rejection Funnel + Reward/Risk Root-Cause Audit

## Purpose
Trace every canonical BUY action row through the existing production-equivalent selector gates without changing any gate.

## Funnel
Each BUY action is classified as:
- confidence and reward/risk both fail
- confidence only fails
- reward/risk only fails
- guardrail fails
- all gates pass but loses ranking to SELL
- all gates pass but loses ranking to another BUY
- all gates pass and becomes the winner

## Ranking
The audit mirrors the existing selector's ranking contract: eligible candidates are ordered by `(calibrated_confidence, reward_risk)` descending. The selector implementation itself is not changed or duplicated into production.

## Scope
Uses only full 7-timeframe coverage dates, 2026-06-15 through 2026-07-07, from the V1.7.3 recovered real Alpaca dataset.

## Safety
Read-only historical diagnostic. No threshold, RR formula, selector ranking, Paper runtime, production parameter, broker write, order submission, or automatic promotion change.
