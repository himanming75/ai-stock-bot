# V2.1 BUY vs SELL Reward/Risk Formula Decomposition + Directional Symmetry Audit

## Purpose
Explain why every BUY action in V2.0 had reward/risk below 1.0 while SELL candidates could pass the same gate.

## Canonical formula
The existing engine computes:
`reward_risk = abs(expected_return) / expected_risk`

Because expected return is absolute-valued in the ratio, there is no explicit BUY/SELL direction multiplier. V2.1 therefore tests whether the observed asymmetry comes from the data-derived components rather than the formula label.

## Compared dimensions
- absolute expected return
- expected risk
- reward/risk
- absolute consensus strength
- timeframe alignment/disagreement
- probability
- calibrated confidence
- mean timeframe ATR
- symbol-level BUY vs SELL summaries
- per-timeframe signal distributions

## Scope
Full 7-timeframe coverage only, 2026-06-15 through 2026-07-07.

## Safety
No RR formula, threshold, direction weighting, timeframe weighting, production parameter, Paper runtime, broker write, order submission, or automatic promotion changes.
