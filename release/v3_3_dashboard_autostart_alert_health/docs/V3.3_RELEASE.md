# V3.3 Dashboard Auto-Start + Alert / Health Layer

V3.3 reuses the existing V3.2 unified dashboard and `/api/status`. It does not create another dashboard server or trading engine.

## Additions
- Alert/Health cards in the existing V3.2 HTML.
- One-shot health snapshot using the existing V3.2 status builder.
- Freshness metadata for Paper session, runtime gate, and 10-day validation sources.
- Safe start on localhost:8766 with duplicate-instance detection.
- Windows logon Scheduled Task `AIStockBot-OperationsDashboard-V3_3`.
- Scheduled Task policy `IgnoreNew` to prevent duplicate V3 dashboard instances.

## Port policy
Legacy V2 on 8765 is not modified. V3 uses 8766.

## Safety
No Paper trading Scheduled Task changes, no broker call/write, no order submission, and no strategy/risk/selector changes.
