# V2.5 Regime-Aware BUY Counterfactual + Net-Cost Lifecycle Audit

## Goal
Identify whether a constrained 1D-opposite BUY regime survives de-duplication, transaction-cost stress, and the existing TP1.5 / SL0.75 / 45-minute lifecycle assumptions.

## Scenario matrix
Symbol groups:
- ALL
- MSFT + NVDA
- MSFT only
- NVDA only
- AAPL only

De-duplication:
- 0 / 15 / 30 / 45 minutes

Round-trip cost stress:
- 0 / 2 / 5 / 10 bps

Forward horizons:
- 30 / 45 minutes

Lifecycle:
- TP +1.5%
- SL -0.75%
- maximum hold 45 minutes
- conservative same-bar ambiguity: SL first

## Diagnostic candidate rule
A scenario survives only if, after 5 bps cost:
- at least 15 observations remain,
- mean return > 0,
- median return > 0,
- win rate > 50%.

This is diagnostic ranking only and does not promote or deploy anything.

## Safety
No regime filter, symbol filter, de-duplication, cost model, RR threshold, 1d weight, Paper runtime, production parameters, broker writes, or order submissions are changed.
