# V3.10 Canonical Trade Detail & Lifecycle Matrix Dashboard

V3.10 extends the already verified canonical Paper performance source into a detailed operator view.

Added detail fields:
- Entry Time / 진입시간
- Exit Time / 청산시간
- Holding Time / 보유시간
- Symbol / 종목
- Entry Price / 진입가
- Exit Price / 청산가
- Quantity / 수량
- Realized P/L / 실현손익
- Realized Return / 실현수익률
- Result / 수익·손실·본전
- Exit Reason / 청산사유
- Exit Order ID / 주문 ID

Filters:
- Date / 날짜
- Symbol / 종목
- Exit Reason / 청산사유
- Result / 수익·손실
- Reset Filters / 필터 초기화

Filtered summary cards:
- trade count
- realized P/L
- win rate
- average holding time

Source remains the canonical lifecycle analytics established in V3.8.1:
`runtime/paper_full_auto_lifecycle/closed_round_trips.jsonl`

No alternative P/L source is introduced.

Safety: read-only dashboard/analytics only. No broker network/write, order submission, Paper runtime modification, production parameter/selector change, or duplicate trading engine.
