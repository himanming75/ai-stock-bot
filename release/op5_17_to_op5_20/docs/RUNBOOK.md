# Promotion Approval Runbook

1. Copy the approval policy example.
2. Run test and verify.
3. Before PROMOTION_READY, WAIT_PROMOTION_READY is expected.
4. After Promotion becomes ready, review the Certificate and Manifest.
5. Record explicit approval with approver name and reason.
6. The same Certificate cannot be approved twice.
7. Certification Gate clear does not enable Live Trading.
