This stage implements an E*TRADE read-only adapter foundation. It follows the
official OAuth 1.0a / HMAC-SHA1 request signing model and separates Sandbox
from Production. Unit tests and certification use FixtureTransport only.

The OAuth request-token, browser authorization, access-token exchange, token
renewal, and token revocation workflows are intentionally not activated in
this stage. No real credentials or network calls are used, and no order
submission or cancellation endpoint is permitted.

This code is designed for the repository owner's own E*TRADE account workflow.
Review E*TRADE's current API agreement and license before any commercial or
third-party deployment.
