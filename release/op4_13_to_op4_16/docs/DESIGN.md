# OP4.13-OP4.16 Paper Risk Monitor

- OP4.13 Calculate current and historical Drawdown
- OP4.14 Calculate gross and per-symbol Exposure
- OP4.15 Evaluate Daily Loss
- OP4.16 Write an Emergency Stop requirement gate

Emergency Stop is a local requirement only. This stage never cancels orders,
closes positions, submits orders, or calls the broker.
