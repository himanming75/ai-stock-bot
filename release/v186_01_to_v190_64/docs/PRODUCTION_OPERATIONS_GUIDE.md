# V186-V190 Production Operations & Reporting

Included:

- daily, weekly and monthly reports
- portfolio and qualification summary
- disk, log and required-result health checks
- timestamped backup snapshots
- SHA-256 backup manifests
- backup retention
- manual restore plan
- production operations certificate
- web Reports/System API

The backup system does not include environment variables or broker credentials.

Restore is never automatic.

Broker writes and Live submission remain disabled.
