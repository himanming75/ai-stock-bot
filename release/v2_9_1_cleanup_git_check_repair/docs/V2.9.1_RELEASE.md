# V2.9.1 Cleanup Git Check Repair

## Root cause
V2.9 used `git ls-files --error-unmatch` while PowerShell had `$ErrorActionPreference="Stop"`.
For an untracked path, Git correctly emitted a pathspec error, but PowerShell treated that expected non-match as a terminating error.

## Repair
V2.9.1 uses:
`$Tracked = @(git ls-files -- "$Target")`

- tracked path: output count > 0 -> refuse deletion
- untracked path: output count = 0 -> safe deletion
- missing path: skip

No tracked project file is deleted.

After cleanup, V2.9 certification is re-run unchanged.
