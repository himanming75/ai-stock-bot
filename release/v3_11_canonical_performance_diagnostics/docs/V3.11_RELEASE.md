# V3.11 Canonical Performance Diagnostics

Adds read-only diagnostics on canonical trade details:
- sample-size guard
- best/worst trade
- average holding time
- win/loss streaks
- symbol diagnostics
- exit-reason diagnostics
- daily diagnostics
- diagnostic notes

Overall sample requires 10 canonical numeric trades.
Each group requires 5 trades.
Below threshold is labeled `INSUFFICIENT_SAMPLE`.

This prevents the current two profitable trades from being treated as statistically reliable.

English/Korean bilingual dashboard labels are included.

Safety: no broker network/write, no order submission, no Paper runtime modification, no production parameter/selector changes, no duplicate trading engine.
