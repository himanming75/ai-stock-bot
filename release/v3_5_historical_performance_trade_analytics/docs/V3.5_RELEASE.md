# V3.5 Historical Performance & Trade Analytics

Extends the existing V3 dashboard with read-only trade analytics from existing runtime JSONL ledgers.

Metrics: observed/numeric closed trades, net realized P/L, wins/losses/breakeven, win rate, gross profit/loss, profit factor, average trade/win/loss, best/worst trade, max realized drawdown, cumulative realized P/L, symbol breakdown, exit-reason breakdown, and daily breakdown.

Historical and current 10-trading-day validation metrics remain separate. Until the validation coordinator establishes a start date, validation analytics report `WAITING_FOR_VALIDATION_START`.

A CLOSED_TRADE record without numeric P/L is counted as observed but excluded from numeric performance calculations. No values are invented.

The verifier launches the actual dashboard direct script on localhost port 8875 and requires V3.4 visualization to remain PASS.

Safety: no broker network/write, no order submission, no Paper runtime modification, no strategy/risk/selector modification, and no duplicate trading engine.
