# Validation Progress Tracker

Adds factual validation progress tracking to Validation Lab.

Tracks:
- target 10 observed validation days;
- target 200 resolved ML outcomes;
- current resolved outcomes;
- waiting future marks;
- AI Health;
- research comparison readiness;
- Paper qualification;
- next milestone and blockers.

Observed validation days are derived only from timestamps already present in:
- completed round-trip ledger;
- AI continuous shadow pipeline cycle ledger.

The tracker never invents trading days, resolved outcomes, or future market marks.
