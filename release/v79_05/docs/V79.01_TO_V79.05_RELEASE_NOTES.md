# V79.01-V79.05 Release Notes

## Added

- Alpaca SDK installation contract and optional installation checker.
- Credential-presence safety gate that never exposes or uses key values.
- Validated bar-request and normalized market-bar data contracts.
- Deterministic offline Alpaca market-data adapter.
- Foundation certificate and independent verification command.
- PowerShell RUN, INSTALL CHECK, and VERIFY entry points.
- Ten unit tests covering safety, contracts, adapter behavior, and certification.

## Safety boundary

This release performs no network request, connects to no broker, submits no order,
uses no real credential, and does not authorize live trading.
