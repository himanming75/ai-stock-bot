# V2.2.15 ML Feature Drift Monitor

Compares the feature distribution seen during V2.2.9 training with recent
V2.2.11 shadow inference feature vectors.

Measures:
- mean shift in training standard-deviation units;
- median shift in training-IQR units;
- current/training standard deviation ratio;
- LOW / MEDIUM / HIGH per-feature drift severity.

This is not portfolio drift/rebalancing.

No automatic retraining, model replacement, selector change, threshold change,
Paper execution change, or Live execution change is allowed.
