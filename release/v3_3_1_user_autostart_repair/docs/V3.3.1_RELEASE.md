# V3.3.1 User Autostart Repair

## Root cause
Windows rejected `Register-ScheduledTask` with:
`0x80070005 Access is denied`.

## Repair
Use the current-user Run key instead:

`HKCU\Software\Microsoft\Windows\CurrentVersion\Run`

Entry:
`AIStockBotOperationsDashboardV3`

Command:
`powershell.exe -NoProfile -WindowStyle Hidden -ExecutionPolicy Bypass -File "C:\stock-bot\START_DASHBOARD_V3_3.ps1"`

This requires no administrator privileges.

## Scope
Only dashboard auto-start is changed.
No Paper runtime, trading Scheduled Task, broker, order, strategy, risk, or selector changes.
