# V281-V290 Multi-Account Engine

Supports multiple Alpaca Paper account definitions, unique credential prefixes, strategy assignment, capital/risk/order/position limits, account kill switches, cross-account conflict prevention, dashboard payloads and audit ledgers.

Credential variable examples:
- ALPACA_PAPER_SCALP_API_KEY / ALPACA_PAPER_SCALP_SECRET_KEY
- ALPACA_PAPER_DAY_API_KEY / ALPACA_PAPER_DAY_SECRET_KEY
- ALPACA_PAPER_SWING_API_KEY / ALPACA_PAPER_SWING_SECRET_KEY

All kill switches default ON. Paper reads/submissions and all Live capabilities default OFF.
