# V2.2 Expected-Return Cancellation / Timeframe Contribution Audit

## Purpose
Explain why BUY absolute expected return was roughly one-third of SELL in V2.1.

## Method
For every full-coverage canonical BUY and SELL analysis:
- retain the canonical per-timeframe expected return and canonical timeframe weight;
- calculate each timeframe's weighted expected-return contribution;
- calculate total absolute contribution;
- calculate opposite-direction contribution;
- calculate cancellation ratio = 1 - abs(net expected return) / sum(abs(weighted contributions));
- compare BUY vs SELL by timeframe and symbol.

## Questions answered
- Are BUY returns weak because bullish timeframes are individually weak?
- Are bullish and bearish timeframe contributions cancelling each other?
- Which of 1m/3m/5m/15m/30m/1h/1d contributes most to BUY vs SELL?
- Are long-term and short-term signals conflicting?

## Safety
No timeframe weights, expected-return formula, RR formula, thresholds, production parameters, Paper runtime, broker writes, order submissions, or automatic promotion are changed.
