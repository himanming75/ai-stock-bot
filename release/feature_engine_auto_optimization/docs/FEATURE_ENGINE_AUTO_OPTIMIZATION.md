# Feature Engine and Auto Optimization Framework

This package adds:

- technical feature generation;
- factor construction;
- normalization;
- correlation filtering;
- feature importance and selection;
- dataset building and fingerprinting;
- ensemble scoring;
- grid and random optimization;
- optimization history;
- champion candidate preview;
- rollback preview.

No machine-learning model is trained. No strategy parameter is changed. No
candidate is promoted. No rollback is performed. No broker or order action
occurs.
