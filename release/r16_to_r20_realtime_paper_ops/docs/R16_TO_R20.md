# R16 to R20 Real-Time Paper Operations Preparation

## R16 Paper Session Coordinator

Creates a Paper session preparation record from the existing R6 runtime session.
It does not start an actual Paper session.

## R17 Market Clock / Scheduler

Evaluates weekday, regular market hours, holidays, and early close using a local
clock model. Automatic runtime start remains disabled.

## R18 Account / Position Sync Preview

Compares local and broker-shaped fixture account/position states. It performs no
broker read and modifies no local state.

## R19 Safe Order Queue

Accepts only an already allowed Paper routing preview whose
`submit_allowed` flag is false. Every queued order has
`dispatch_allowed=false`. The dispatch method always raises an error.

## R20 Order Lifecycle Monitor

Records a preview-only lifecycle through validated, monitored, and completed
states. Automatic retry and automatic order replay remain disabled.

P2 and P3 Actual validation are still required before an actual R16 Paper
session can be developed or executed.
