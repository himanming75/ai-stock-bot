# Runtime Service, Deployment, Packaging, Diagnostics, and Dashboard 6.0

This package provides:

- Windows runtime service definitions in preview-only form;
- service start/stop, PID, lock, graceful shutdown, and restart policies;
- build, release, and version manifests;
- backup, restore, and rollback previews;
- release ZIP creation and SHA256 verification;
- pre-install audit and post-install verification;
- CPU and disk diagnostics;
- runtime health aggregation;
- deployment and version audit ledgers;
- read-only Dashboard 6.0.

No Windows service is installed. No process is started. Automatic start and
automatic restart are disabled. No backup, restore, rollback, release,
network, broker, or order action occurs.
