# OP4.01-OP4.04 Controlled Paper Pilot Foundation

- OP4.01 Validate pilot prerequisites and construct deterministic Pilot ID
- OP4.02 Create one Paper pilot session
- OP4.03 Create registry and active runtime lock
- OP4.04 Write a read-only Dashboard pilot state

The pilot cannot start while open orders or recovery obligations remain.
This stage does not call the broker and cannot submit, cancel, or replace orders.
