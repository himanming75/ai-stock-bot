# V3.15 Strategy Robustness & Failure Boundary

V3.15 extends V3.14 stress testing by finding approximate failure boundaries.

## Boundaries
- Break-even friction, bps per leg
- Winner haircut percentage where Net P/L reaches zero or below
- Loss amplification percentage where Net P/L reaches zero or below
- Friction where Profit Factor falls to 1 or below
- Friction where readiness status fails

## Observability rule
If there are no observed losing canonical trades, the loss-amplification boundary is explicitly:
`UNOBSERVED_NO_LOSING_TRADES`

The system does not invent a loss boundary from nonexistent losses.

## Robustness score
Boundary values are normalized into a descriptive robustness score.

If fewer than 10 canonical numeric trades exist:
- sample status remains `INSUFFICIENT_SAMPLE`
- displayed robustness score is capped at 49/100
- raw score is retained separately

This prevents a tiny favorable sample from appearing robust.

## Safety
All transformations use copied canonical trades.

No:
- canonical runtime file modification
- broker network/write
- order submission
- Paper runtime modification
- production parameter/selector modification
- automatic promotion
- Live approval
