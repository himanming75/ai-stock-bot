# V3.2.1 Git Discovery / API Repair

## Root cause
The V3.2 HTML page served correctly, but `/api/status` crashed because the spawned dashboard Python process could not resolve `git.exe`.

Observed error:
`FileNotFoundError: [WinError 2] The system cannot find the file specified`

## Repair
- Discover Git from PATH first.
- Fall back to common Windows Git install paths.
- If Git is unavailable, return a safe dashboard status instead of crashing the API request.
- Preserve localhost/read-only behavior.
- No broker, order, strategy, runtime, or production changes.

## Expected result
`/api/status` returns JSON even when Git cannot be found by the spawned process.
