# V291-V300 Paper Qualification & Broker Reconciliation

Features:

- internal vs broker account reconciliation
- cash, equity and buying-power comparison
- position quantity comparison
- order-status comparison
- partial-fill, fill and cancel coverage
- duplicate-order detection
- restart-recovery evaluation
- unresolved mismatch tracking
- Paper session and cycle requirements
- reconciliation pass-rate requirement
- win rate, profit factor and drawdown checks
- qualification ledger
- web API foundation

Safety defaults:

- Paper reading disabled until explicitly configured
- Paper submission disabled
- Live submission and network disabled
- Broker write disabled

This stage evaluates qualification. It does not submit orders.
