# V3.16 Market Regime Performance Analysis

V3.16 adds evidence-only market regime analysis for canonical Paper trades.

## Important design rule
The system does NOT infer Bull/Bear/Sideways or volatility regime from entry/exit price movement.

It searches runtime JSONL records linked to canonical identifiers and accepts only explicit regime fields such as:
- market_regime
- regime
- trend_regime
- market_state
- volatility_regime
- vol_regime
- volatility_state

Recognized values normalize to:
- BULL
- BEAR
- SIDEWAYS
- HIGH_VOL
- NORMAL_VOL
- LOW_VOL

If no explicit evidence exists, the regime remains UNOBSERVED.

## Metrics
- trade count
- Net Realized P/L
- Win Rate
- Profit Factor
- Average P/L
- Max Realized Drawdown
- sample status

## Sample guards
- fewer than 10 total canonical numeric trades: INSUFFICIENT_SAMPLE
- fewer than 5 trades in an observed regime: group INSUFFICIENT_SAMPLE
- zero observed trades: UNOBSERVED

## Safety
- explicit evidence only
- no price-based regime guessing
- no canonical/runtime modification
- no broker write
- no order submission
- no Paper runtime modification
- no automatic promotion
- no Live approval
