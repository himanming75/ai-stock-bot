# V2.3 1D Regime Conflict Counterfactual + BUY Outcome Validation

## Purpose
Determine whether BUY actions rejected while 1d was HOLD or SELL would actually have performed poorly, before considering any regime-aware weighting change.

## Groups
Canonical BUY action rows are grouped by the existing 1d timeframe signal:
- 1D_ALIGNED_BUY
- 1D_HOLD
- 1D_OPPOSITE_SELL

## Outcome evaluator
This is a diagnostic path evaluator, not a replacement lifecycle engine.
For each canonical BUY action:
- enter at the first available 1-minute bar open after the checkpoint;
- TP = +1.5%;
- SL = -0.75%;
- maximum hold = 45 minutes;
- if TP and SL are both touched within one bar, SL is assumed first (conservative ambiguity rule);
- otherwise exit at the final available close within 45 minutes.

The evaluator also records MFE and MAE.

## Safety
No 1d weight change, RR threshold change, production lifecycle change, Paper runtime change, broker write, order submission, or automatic promotion.
