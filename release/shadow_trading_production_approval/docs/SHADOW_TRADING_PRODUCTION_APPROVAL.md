# Shadow Trading and Production Approval Framework

This package adds:

- shadow order intake;
- simulated latency and slippage;
- simulated fills;
- shadow portfolio and PnL;
- shadow risk metrics;
- shadow trade ledger;
- production approval queue;
- deployment lock;
- emergency-stop preview;
- approval ledger;
- rollback approval preview;
- release gate.

Every trading event is simulated. No broker, order, fill, portfolio, production
approval, emergency-stop activation, release, or rollback action is performed.
