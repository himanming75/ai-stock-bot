# V3.18.1 UI Integration Repair

The original V3.18 UI patch expected `renderWeaknessMap(a);`, but V3.17 actually uses an independent `refreshWeaknessMap()` -> `/api/status` -> `loadWeaknessMap(data)` flow.

V3.18.1 repairs the integration by adding:
- `loadImprovementCandidates(d)`
- `refreshImprovementCandidates()`
- independent `/api/status` fetch
- independent 30-second refresh

This package is designed for the partial state where V3.18 API patch succeeded but UI patch failed before commit/push.

Safety remains unchanged: no broker write, no order submission, no Paper parameter change, no Live change, no automatic strategy change.
