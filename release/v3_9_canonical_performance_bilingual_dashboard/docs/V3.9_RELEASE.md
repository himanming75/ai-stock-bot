# V3.9 Canonical Performance Dashboard Unification + Korean Bilingual UI

V3.8.1 established `runtime/paper_full_auto_lifecycle/closed_round_trips.jsonl` as the canonical performance source.

V3.9 removes conflicting dashboard metrics by making the upper Performance cards and Daily Realized P/L visualization use the same canonical analytics as the lower Trade Analytics section.

Changes:
- Historical Closed Trades -> canonical numeric trade count
- Historical Realized P/L -> canonical net realized P/L
- Win Rate -> canonical win rate
- Profit Factor -> canonical profit factor
- Daily Realized P/L chart -> canonical daily analytics
- visualization summary -> canonical historical realized values
- major dashboard labels -> English / Korean bilingual display

Examples:
- System Health / 시스템 상태
- Account Equity / 계좌 평가금액
- Current Positions / 현재 보유 포지션
- Performance / 성과
- Win Rate / 승률
- Daily Realized P/L / 일별 실현손익
- Historical Performance & Trade Analytics / 누적 성과 및 거래 분석

Direct runtime verification uses localhost port 8879 and confirms that upper summary values equal canonical analytics, Korean labels are served in live HTML, and the daily P/L chart is populated when numeric trades exist.

Safety: read-only dashboard/analytics only. No broker network/write, order submission, Paper runtime modification, production parameter/selector modification, or duplicate trading engine.
