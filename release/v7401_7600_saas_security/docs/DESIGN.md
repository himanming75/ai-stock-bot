This package adds a security-focused SQLite layer, strong password policy,
failed-login lockout, persisted sessions, password reset tokens, email
verification tokens, TOTP MFA, read-only API tokens, user activation and lock
management, workspace role updates, security auditing, and an admin dashboard
fixture.

External email delivery, external MFA providers, CSRF protection for public
deployment, broker credential storage, broker writes, and order submission
remain disabled.
