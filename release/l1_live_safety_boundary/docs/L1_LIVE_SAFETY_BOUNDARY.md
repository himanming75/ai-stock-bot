# L1 Live Safety Boundary

L1 prepares the safety boundary for future Live qualification.

Included:

- Paper and Live credential fingerprint separation;
- no raw credential output;
- dedicated Live Kill Switch, active by default;
- Live order, daily order, daily loss, total exposure, and position limits;
- symbol and account allowlists;
- two-step confirmation gate;
- Paper completion gate;
- Paper and Live endpoint separation.

L1 does not allow Live read access, Live network access, Live write access, or
Live order submission. L2 may begin only after P5 Actual Paper qualification.
