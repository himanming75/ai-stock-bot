# V3.1 Operations Dashboard Foundation

## Goal
Provide a local read-only web dashboard for operating the existing AI Stock Bot during the two-week Paper validation.

## Reused sources
- V2.9.4 runtime observation gate report
- V3.0 two-week validation report
- V2.7 shadow snapshot/ledger
- V2.8.1 hook ledger
- existing Paper autonomous session ledger
- local Git HEAD/origin-main status

## UI
Local URL: `http://127.0.0.1:8765`

Cards:
- System Health
- Runtime Observation Gate
- Two-Week Paper Validation
- Paper Session
- Shadow Candidate
- Safety
- Recent Runtime Events

The browser refreshes the read-only status API every 15 seconds.

## API
- `GET /`
- `GET /api/status`
- `GET /health`

There are no POST/PUT/DELETE endpoints.

## Safety
No broker client, no order submission, no strategy/selector/risk changes, no Scheduled Task changes, and no automatic promotion.
