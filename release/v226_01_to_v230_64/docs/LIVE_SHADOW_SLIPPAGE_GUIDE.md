# V226-V230 Live Shadow & Slippage Qualification

This stage compares Paper signals with a read-only Live quote snapshot.

Calculated values:

- Bid, Ask, Last and Mid
- Spread and Spread %
- Expected Live fill price
- Expected Slippage and Slippage %
- Buying Power requirement
- Qualification score
- Daily Shadow statistics

Safety:

- Live submission disabled
- Broker write disabled
- Actual Live orders zero
- Real Live reads disabled by default
