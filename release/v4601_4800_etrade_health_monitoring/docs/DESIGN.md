This stage evaluates E*TRADE read-path health using OAuth state, response
latency, error rate, rate-limit status, account status, and snapshot integrity.
The resulting score controls read-only routing modes.

Any critical signal immediately activates FAILSAFE_BLOCKED. Broker writes,
order submission, and cancellation remain disabled in every routing mode.
