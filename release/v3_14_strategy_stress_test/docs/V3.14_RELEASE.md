# V3.14 Strategy Stress Test

V3.14 adds a simulation-only stress layer over canonical Paper trades.

Scenarios:
- Baseline: 0 bps friction/leg, 0% winner haircut, 0% loss amplification
- Mild: 2 bps/leg, 5% winner haircut, 5% loss amplification
- Moderate: 5 bps/leg, 10% winner haircut, 15% loss amplification
- Severe: 10 bps/leg, 20% winner haircut, 30% loss amplification

Metrics per scenario:
- Net Realized P/L
- Win Rate
- Profit Factor
- Average Trade
- Best/Worst Trade
- Max Realized Drawdown
- Simulated friction cost
- V3.11 diagnostics
- V3.12 readiness status and score

Fewer than 10 canonical numeric trades:
`INSUFFICIENT_SAMPLE`

Canonical trades are deep-copied before stress transformation. No canonical source file is modified.

Safety:
- simulation only
- no broker network/write
- no order submission
- no Paper runtime modification
- no production parameter/selector modification
- no automatic promotion
- no Live approval
