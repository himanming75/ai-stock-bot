This is the first original-roadmap SaaS package. It establishes users,
workspaces, memberships, role-based access control, password hashing, signed
sessions, strategy and risk settings, broker connection metadata, audit logs,
a local REST API, and a basic dashboard.

This package deliberately excludes production persistence, MFA, email
verification, billing, cloud deployment, broker credential storage, broker
writes, and order submission.
