# L4 Live Reconciliation Preparation

L4 prepares offline reconciliation for future Live operation:

- broker order state vs expected order;
- duplicate Fill protection;
- expected vs actual position quantity;
- expected vs actual cash and buying power;
- Drift detection;
- reconciliation ledger;
- manual repair plan.

Automatic repair, automatic position mutation, and automatic order replay remain
disabled. Actual Live reconciliation requires P5 Actual Paper completion, L2
Actual Live Read, and L3 Actual Micro-Live qualification.
