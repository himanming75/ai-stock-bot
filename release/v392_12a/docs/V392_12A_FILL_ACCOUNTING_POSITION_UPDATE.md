# V392.12A Fill Accounting and Position Update

## Purpose

Apply a local V392.11A Fill Event to a local Paper Portfolio.

## Accounting behavior

- Cash balance update;
- Position quantity update;
- Weighted average cost;
- Realized P&L;
- Unrealized P&L;
- Portfolio equity;
- Full fill;
- Partial fill;
- No fill;
- Replay protection;
- Accounting Event and Portfolio hashes.

## Boundary

This stage updates only local Paper Portfolio files. It does not contact a
broker and does not submit Paper or Live orders.
