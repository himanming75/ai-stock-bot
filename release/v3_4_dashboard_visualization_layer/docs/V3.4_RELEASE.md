# V3.4 Dashboard Visualization Layer

## Goal
Extend the existing V3.2/V3.3 unified operations dashboard with read-only visualizations.

## Reuse / no duplication
V3.4 wraps the existing `build_status()` implementation and reuses local runtime JSON/JSONL files.

## Added
- Equity curve
- Daily realized P/L bars
- Current position allocation
- 10-trading-day validation progress
- Current unrealized P/L
- Equity/P&L point counts

## Data policy
If historical points are unavailable, the dashboard explicitly shows a no-data state instead of inventing values.

## Rendering
Browser-native SVG only. No Chart.js, Plotly, D3, CDN, or new Python dependency.

## Cleanup
Safely removes the obsolete untracked administrator Scheduled Task installer from V3.3 if it still exists. A tracked file is never removed.

## Safety
Read-only dashboard only. No broker network/write, no order submission, no Paper runtime changes, and no strategy/risk/selector changes.
