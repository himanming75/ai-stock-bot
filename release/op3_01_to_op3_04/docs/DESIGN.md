# OP3.01-OP3.04 Controlled Paper Order Preparation

- OP3.01 Create a Paper order candidate payload
- OP3.02 Enforce quantity, notional, daily-limit, duplicate, market, and stop gates
- OP3.03 Verify a manual preparation approval phrase
- OP3.04 Write a preparation readiness token

This bundle never sends an order and never performs a network write.
