# V421.01–V430.64 AI Portfolio Intelligence

## Purpose

Compare multiple offline AI signals and produce a ranked, diversified portfolio proposal.

## Features

- candidate scoring;
- confidence/risk/liquidity ranking;
- BUY-only selection;
- sector concentration limits;
- maximum-position limits;
- single-position weight cap;
- dynamic cash reserve;
- selected and excluded candidate explanations;
- append-only local portfolio memory.

All weights are recommendations only. No broker client is imported and no order can be submitted.

