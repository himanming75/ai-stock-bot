The lab registers eleven strategy variants across EMA, RSI, MACD, Momentum, and Bollinger categories. It runs them against the historical source selected by V89, evaluates the existing performance gate, ranks all candidates, and issues a Champion only when a strategy is approved.

All operations remain local and paper-only.
