# V411.01–V420.64 AI Signal Intelligence

This stage extends V400 with offline OHLCV signal analysis.

## Features

- EMA trend alignment;
- RSI momentum;
- MACD component;
- ATR volatility;
- relative-volume strength;
- candlestick pattern detection;
- signal score and A/B/C/D rank;
- 0–100 risk score;
- expected holding-period label;
- explainability and self-review;
- append-only local signal-memory ledger.

BUY and SELL remain analytical labels. The package has no broker client and cannot submit orders.
